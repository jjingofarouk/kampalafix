# KampalaFix

**KampalaFix** is your home service hub, connecting you with trusted electricians, plumbers, cleaners, and carpenters in Kampala. Book services by location and availability, with features like real-time chat, ratings, payments, and calendar syncing — all built to impress and scale.

---

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/kampalafix.git
   cd kampalafix

	2.	Install dependencies

npm install


	3.	Configure environment variables
Create a .env file in the root and add the necessary Firebase, Stripe, and app config values.
	4.	Run the development server

npm run dev

Features

	•	Book services with real-time availability
	•	In-app chat between users and providers
	•	Secure payments powered by Stripe
	•	Calendar integration for seamless scheduling
	•	User ratings and verified reviews
	•	Location-based service discovery and filtering
	•	Optimized, mobile-first UX for urban users

Tech Stack

	•	Frontend: Next.js, React, TypeScript, Tailwind CSS
	•	Backend: Firebase (Auth, Firestore, Functions)
	•	State Management: Redux Toolkit
	•	Payments: Stripe API
	•	Maps & Geo: Google Maps API (optional)
	•	Dev Tools: ESLint, Prettier, Husky, Vercel
